# Short lifetime KeyPackage WASM rehearsal

Status: both local ZIP artifacts complete; actual UHM browser/server/migration gate remains unverified. Authoritative status: [OpenMLS TODO](todo.md) (`KP-TTL-REHEARSAL-001..003`). Bellboy's environment gates remain in the [MLS lifecycle ledger](../../../bellboy/docs/todo/e2ee_mls_keypackage_lifecycle_plan.md).

## Goal and scope

Produce two copyable ZIP files with a Web-target OpenMLS WASM four-file set and instructions. The internal artifact is labeled for Bellboy `3a3d81dc04b6938ad507dc2eca1434985e8799f5`; the external artifact is labeled for bellboy-external `d6d2bfec9f296914a6c11e7425568ab5e6bb7fe1`. They generate freshly signed KeyPackages whose `Lifetime.not_after` is generation time plus 605400 seconds (7 days + 10 minutes). This permits a short observation of Bellboy's current 604800-second minimum remaining lifetime boundary. It does not alter old Bellboy commits, migrate a database, modify existing KeyPackages, or qualify a shared environment.

Acceptance: each ZIP contains matching generated JS, declarations, WASM, a source patch, manifest/hashes, and application instructions; a runtime probe proves the signed lifetime; JS/WASM import/export compatibility is checked against the consumer's actual glue. Server acceptance and expiry behavior need separate isolated server/UHM evidence.

## Source and design

- Internal build input: current clean OpenMLS source `4f5f03304b8515a19c2a0e55b2fb3349bdb7c42f`, with a private worktree and its existing Cargo.lock. The internal UHM source artifact is not pinned to Bellboy's 2026-08-04 commit in the [scenario](../../../bellboy/docs/mls_migration_upgrade_test_scenario.md); compatibility with that old server is an open gate.
- External build input: OpenMLS `ce0ed8fde928db16f1c4709c30d18f2aaa4507c2`, the external SDK's pinned live-only source, and pinned Cargo.lock from `ermis-chat-monorepo/packages/ermis-chat-sdk/wasm-build`. The JOIN/historical patches were tested and then removed from this artifact because they introduce an import absent from the SDK's bundled JS glue. The external app currently pins SDK/React `2.1.0-external.4`; this artifact has the same generated public JS/declarations and WASM import/export names as its normal artifact. Do not promote internal PIN/archive exports into this distribution.
- Call path: UHM/SDK invokes `Identity.key_package(s)` -> `openmls-wasm/src/identity.rs` -> `OpenMlsKeyPackage::builder().key_package_lifetime(Lifetime::new(605400)).build` -> signed LeafNode lifetime -> Bellboy upload/consume. Core `Lifetime::default()` stays 84 days. Existing provider keys remain local to the consumer.
- Current Bellboy uses `not_after >= trusted_now + minimum_remaining_lifetime` with the default minimum 604800 seconds; crossing the 10-minute buffer should change `selected` to `only_near_expiry` when the feature is present and inventory is otherwise valid. Both requested old commits predate that metadata/selection contract and cannot show this server outcome without a newer target server.
- Rejected: changing the core default lifetime would affect non-WASM clients and tests; changing only `openmls_wasm_bg.wasm` without checking the bundled JS ABI risks runtime breakage; setting TTL below seven days would make the package unusable immediately on current Bellboy.
- Compatibility/rollback: these are test-only artifacts. Restore the original four-file set/SDK release and reload browser state to stop creating short lifetime packages. Already uploaded short lifetime packages retain their signed expiry; use isolated accounts/devices and restore the scenario database/namespace when repeating a baseline.
- Cost: KeyPackage generation remains O(1) per package, O(K) for K packages, with the same memory, byte payload shape, and zero added DB/network round trips. Server selection remains its existing O(N+P) bounded scan over inventory and selected packages. The test changes validity timing, not contention or scaling. Benchmark gate is unchanged; record per-package size and normal server metrics if this artifact is used in a load test.
