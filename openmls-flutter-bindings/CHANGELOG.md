# Changelog

## 0.1.0

- Added the OpenMLS Dart API generated by flutter_rust_bridge 2.13.0.
- Added a Native Assets build hook so Flutter applications consume one package
  while Rust is compiled and bundled for the selected platform automatically.
- Added an actual Flutter consumer smoke test that uses the default FRB loader.
- Added exported-symbol audits and a universal ARM64/x86_64 iOS simulator slice
  to manual release-artifact verification.
- Aligned the Cargo package and library names so Native Assets resolves the
  generated dependency file and library correctly.
